# Какой ты персонаж из аниме?

Заготовка опросника на React, Vite и Tailwind CSS.

## Запуск

Для запуска нужен Node.js (версия LTS). После его установки в этой папке выполните:

```bash
npm install
npm run dev
```

## Данные опроса

Вопросы и варианты находятся в `src/quizData.js`. Когда будут готовы персонажи и веса, сюда будет добавлена схема ответов и подсчёт результата.
